## ⭐ 精選：KAF Observatory

<a href="https://kaf-observatory.vercel.app">

為虛擬歌手 **KAF（花譜）** 打造的 3D 聆聽室。

- 🖥️ **桌機版**：牆上的螢幕播放 MV，檯燈和時鐘跟著音樂脈動。
- 📱 **手機版**：直播行程表，以及收錄 245 首歌的播放器。
